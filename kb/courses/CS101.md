## Overview
CS101 Introduction to Programming is a 4-credit-hour core course at academic level 1. It is offered in every semester (Fall and Spring). There are no prerequisites or other registration requirements.

## Description
Introduces programming with Python: variables, control flow, functions, lists and dictionaries, file input and output, and debugging. Students solve small computational problems and learn to write readable, tested code.

## Topics
Python syntax; conditionals and loops; functions; lists, tuples, dictionaries; file handling; debugging and unit testing basics.
